# AI Academic Recovery & Course Progress Agent

An intelligent academic monitoring, course progress tracking, risk prediction, and automated recovery planning system for educational institutions.

## Architecture

- **Frontend**: Next.js / TypeScript / React
- **Backend**: FastAPI / Python
- **AI Agent**: Custom Python-based reasoning engine & predictive models
- **RAG Engine**: LangChain & ChromaDB for document retrieval (syllabus, academic rules, regulations)
- **Database**: PostgreSQL

## Project Structure

```
ai-academic-recovery-agent/
├── frontend/          # Next.js web application
├── backend/           # FastAPI backend service
├── ai_agent/          # Predictive and recovery decision agent
├── rag/               # Retrieval-Augmented Generation pipeline & vector DB
├── database/          # SQL schemas and seed data
├── integrations/      # Integrations with existing academic modules
├── notifications/     # Email, push, and alert services
└── tests/             # Unit and integration test suite
```
